# Preciser

> Preciser is an AI/computer-vision sports analytics platform that turns basketball and baseball game footage into statistics, insights, and live stats feeds. Its API delivers game chart data and opponent-team data as feeds and widgets. Backed by 500 Global and the NVIDIA Inception Program.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public API index and marketing site; it is not published by Preciser.

## API
- [Preciser API index](https://api.preciser.io/): Live welcome/index advertising the API endpoints.
- [Preciser APIs (product page)](https://preciser.io/apis): Live stats feeds and widgets offering.
- Base URL: https://plg-api.preciser.io/v1
- Endpoints:
  - GET /chart-data/id/{gameId} — chart/statistics data for a game
  - GET /opp-team-data/id/{seasonId} — opponent-team data for a season
